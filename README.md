# 鉴宝小店（Treasure Shop）—— 微信小游戏框架

一款“每日逛店淘宝、凭线索辨真假、低买高卖”的经营类小游戏框架。
本仓库是可运行的**基础骨架**：核心玩法闭环已实现，美术与文案均为占位，方便在其上扩展。

## 玩法循环

```
每日 0 点刷新货架（按日期种子，可复现）
        │
        ▼
浏览商品 ──► 查看线索（每件 3 条：2 真 + 1 干扰，顺序打乱）
        │
        ▼
   决定是否买入（花金币）
        │
        ▼
 ┌───────────────┬──────────────────┐
 │ 付费官方鉴定  │  不鉴定直接转手   │
 │ 揭晓真假      │  凭自己判断报价   │
 │ 真品高价回收  │  猜对赚 / 猜错亏  │
 └───────────────┴──────────────────┘
        │
        ▼
 金币增长 / 亏损 ──► 第二天再来
```

- **每日刷新**：`core/rng.js` 用日期字符串做随机种子，同一天进入游戏货架完全一致，跨天自动重刷。
- **真假判断**：`data/clues.js` 维护“真品线索 / 赝品线索 / 中性烟雾弹”三个池子，`core/appraisal.js` 负责组线索、洗牌与官方鉴定。
- **经济系统**：`core/economy.js` 定义初始金币、每日奖励、鉴定费与四种卖出结算（看对真品 / 看走眼 / 识破赝品 / 及时止损）。
- **存档**：`core/save.js` 用 `wx.setStorageSync` 保存金币、背包与上次刷新日期。

## 目录结构

```
game.json / game.js / project.config.json   小游戏入口与工程配置
src/
├── main.js               启动引导：画布、读档、跨天刷新、触摸分发
├── core/
│   ├── rng.js            种子随机数（每日可复现的关键）
│   ├── shop.js           每日货架生成（抽 N 件、定真假、定售价）
│   ├── appraisal.js      线索生成 + 官方鉴定
│   ├── economy.js        钱包、价格与买卖结算规则
│   └── save.js           本地存档读写
├── data/
│   ├── items.js          物品池（名称 / 品类 / 基准价 / 真品率）
│   └── clues.js          线索文案池（真 / 假 / 中性）
├── scenes/
│   ├── sceneManager.js   极简场景栈（push / pop / render / onTap）
│   ├── shopScene.js      商店货架
│   ├── detailScene.js    商品详情 + 线索 + 买入
│   └── bagScene.js       背包：鉴定 / 转手 / 出售
└── ui/
    └── button.js         Canvas 矩形按钮（绘制 + 命中检测）
```

## 运行方式

1. 安装并打开**微信开发者工具**；
2. 选择“导入项目”，目录指向本仓库，AppID 可先选“测试号”；
3. 编译类型为“小游戏”，点击编译即可在模拟器中试玩。

## 扩展方向（建议路线）

- **内容量**：往 `data/items.js`、`data/clues.js` 里加物品和线索即可，无需改逻辑；
- **可信度系统**：让部分线索本身有真有假（卖家可能撒谎），增加博弈深度；
- **价格波动**：给物品加行情系数，同一物品不同日期价格浮动；
- **图鉴收集**：集齐真品图鉴给长期目标；
- **云存档 / 排行榜**：把 `core/save.js` 替换为微信云开发，接好友排行榜；
- **UI 升级**：当前是纯 Canvas 文本界面，可替换为帧动画 / 图片素材，或引入引擎（如 Cocos、Laya）重构表现层。
